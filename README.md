# Session-Based Recommendation: Predicting the Next Product

Рекомендательная система, которая предсказывает следующий товар, который пользователь откроет в рамках сессии, основываясь на последовательности предыдущих просмотров.

Проект выполнен в рамках отборочного задания на образовательный трек **«Рекомендательные системы и ИИ» от НИУ ВШЭ × Сбер**. По результатам выполнения задания я прошла на трек.

## Результаты

Основная модель — граф переходов между товарами — показала более высокое качество рекомендаций по сравнению с популярностным baseline.

| Модель | Hit@10 |
|---|---:|
| Популярные товары (Baseline) | 0.3840 |
| **Граф переходов** | **0.5142** |

**Улучшение Hit@10:**
- +0.1302 в абсолютном значении
- +13.02 процентного пункта
- около +33.9% относительно baseline

Hit@10 показывает долю сессий, для которых целевой товар оказался среди десяти рекомендованных.

## Данные

Для эксперимента используется синтетический e-commerce датасет.

Основные характеристики:
- 2 565 пользовательских сессий
- 400 уникальных товаров
- Средняя длина сессии — около 10.47 товара
- Длина сессии — от 3 до 20 товаров

Данные хранятся в формате JSON Lines (`sessions.jsonl`). Каждая строка представляет собой последовательность идентификаторов товаров в порядке их просмотра.

## Подход

### 1. Анализ данных (EDA)

Проведён первичный анализ датасета:
- количество пользовательских сессий;
- число уникальных товаров;
- средняя, минимальная и максимальная длина сессии;
- частота просмотров товаров;
- распределение длин сессий.

### 2. Подготовка данных

Последний товар каждой сессии используется в качестве целевого значения, а предшествующие товары — как история взаимодействия пользователя.

Таким образом, задача сводится к предсказанию следующего товара по предыдущим действиям.

### 3. Построение графа переходов

Используется граф переходов между товарами:
- вершины соответствуют товарам;
- направленные рёбра отражают последовательные переходы между товарами внутри сессий;
- вес ребра определяется частотой перехода от одного товара к другому.

На основе частот рассчитываются условные вероятности переходов:

\[
P(j \mid i) = \frac{N(i \rightarrow j)}{\sum_k N(i \rightarrow k)}
\]

где:
- \(i\) — текущий товар;
- \(j\) — следующий товар;
- \(N(i \rightarrow j)\) — количество переходов от товара \(i\) к товару \(j\).

### 4. Формирование рекомендаций

Для последнего просмотренного товара выбираются наиболее вероятные следующие товары.

Если информации о переходах недостаточно, список рекомендаций дополняется наиболее популярными товарами из обучающей выборки.

В результате формируется список из 10 рекомендаций.

### 5. Оценка качества

В качестве основной метрики используется **Hit@10**.

Результат графовой модели сравнивается с baseline, который рекомендует десять наиболее популярных товаров независимо от истории конкретной сессии.

## Запуск проекта

### Требования

- Python 3.8+
- Matplotlib

### Установка

Клонируйте репозиторий:

\```bash
git clone https://github.com/ekatizzz/Predicting_the_next_product.git
cd Predicting_the_next_product
\```

Установите зависимость:

\```bash
pip install matplotlib
\```

Запустите решение:

\```bash
python solution.py
\```

После запуска программа:
1. Загружает пользовательские сессии из `sessions.jsonl`.
2. Выполняет анализ данных.
3. Строит граф переходов между товарами.
4. Формирует рекомендации.
5. Рассчитывает Hit@10 для графовой модели и baseline.
6. Выводит результаты сравнения.
